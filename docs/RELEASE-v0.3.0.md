# 电脑时光机 v0.3.0 · 交互与视觉优化

推荐下载 **PC-Timeline-Setup-0.3.0-x64.exe**，双击安装后打开桌面“电脑时光机”。无需 Node.js、账号、管理员权限或命令窗口。

想先试用可下载 **PC-Timeline-Portable-0.3.0-x64.exe**，两种 EXE 只选一个即可。适用于 Windows 10/11 x64。

## 本次改进

- 新记录先提示，不直接挤到正在阅读的时间轴前面；切页保留阅读位置。
- 指定日期和今天/最近 7 天不再叠加冲突。
- 详情可以连续浏览上一条、下一条，支持方向键和 Escape。
- 设置显示未保存状态，支持撤销；保存按钮仅在实际更改时可用。
- 慢请求期间按钮保持锁定，迟到响应不会覆盖刚保存或暂停的状态。
- 连接失败保留旧数据，提供重连；保存失败保留未保存选择。
- 修复隐藏页面刷新后图表可能不显示的问题。
- 提升文字可读性、点击区域和导航状态；通知不再推动页面。
- 区分未开始记录的日期与已记录的零项变化。

23 项自动化测试通过，并完成浏览器交互、三种宽度截图及真实 Windows 桌面运行检查。

## 升级与隐私

先退出旧软件，再安装新版。历史仍保存在当前用户的 `%APPDATA%\PC Timeline\data`，不会主动清空。安装版和便携版共用这份历史。

不上传数据、不读取文件内容、不修改驱动、不自动删除文件。安装包和公开截图不包含开发者的真实电脑记录。

当前仍是预览版。安装包未签名，Edge 或 SmartScreen 可能提示发布者未知。请只从本仓库下载并对照 **SHA256SUMS.txt** 核对，不要关闭系统安全保护。Source code ZIP/TAR 是开发源码，不是安装程序。
