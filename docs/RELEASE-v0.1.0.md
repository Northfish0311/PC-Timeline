# 电脑时光机 v0.1.0 · 首个 Windows 预览版

下载 **PC-Timeline-Setup-0.1.0-x64.exe**，双击安装后打开桌面“电脑时光机”。无需 Node.js、账号、管理员权限或命令窗口。

不想安装可下载 **PC-Timeline-Portable-0.1.0-x64.exe**，双击运行。两者只需选一个，均适用于 Windows 10/11 x64。

本版包含：

- 本地变化时间轴及分类筛选。
- 磁盘总量、可用空间和较大容量变化。
- USB 接入/移除记录及当前接口列表。
- 桌面软件登记、版本变化与搜索。
- 暂停恢复和不含名称/私人路径的 PNG 日报。
- 独立软件窗口，自动分配本机端口。

隐私：数据仅保存在本机 `%APPDATA%\PC Timeline\data`。安装包不包含开发者电脑的记录，不上传数据、不读取文件内容、不自动删除文件。

记录从首次启动后开始，每分钟采样，短暂插拔可能漏记。软件登记来自注册表，不涵盖所有应用；磁盘容量变化尚不能定位具体文件。预览版不能解释所有电脑故障。

安装包未签名，Edge/SmartScreen 可能提示发布者未知。请确认从本仓库下载并对照 **SHA256SUMS.txt** 校验，不要关闭系统安全保护。Source code ZIP/TAR 是开发源码，不是安装程序。
