# 电脑时光机 v0.4.0 · 更好找，也更好读

推荐下载 **PC-Timeline-Setup-0.4.0-x64.exe**，双击安装后打开桌面“电脑时光机”。无需 Node.js、账号、管理员权限或命令窗口。

想先试用可下载 **PC-Timeline-Portable-0.4.0-x64.exe**。两种 EXE 只选一个，适用于 Windows 10/11 x64。

## 本次更新

- USB 设备和软件分标签管理，分别搜索名称、类别与版本，切换时保留各自搜索词。
- 多关键词搜索与结果高亮；时间轴分类显示当前条件下的记录数量。
- 舒适/紧凑列表切换，搜索与分类栏滚动时保持可见。
- 切页后保留时间轴内容、展开数量和阅读位置，新记录先提示。
- 概览数字可直接打开对应列表，最近变化补充日期。
- 磁盘曲线可查看真实采样时间和容量，小幅变化以 MiB、KiB 或 B 显示。
- 详情补充容量净变化；切换上一条/下一条时回到详情顶部。
- 改善窄窗口布局、长名称、断线提示和检查中的反馈。

28 项自动化测试及浏览器交互回归通过，完成不同窗口宽度的截图检查。

## 升级与下载提示

先退出旧软件，再安装新版。历史仍保存在当前用户的 `%APPDATA%\PC Timeline\data`，安装版和便携版共用这份记录。

当前仍是预览版。安装包未签名，Edge 或 SmartScreen 可能提示发布者未知。请只从本仓库下载，并对照 **SHA256SUMS.txt** 核对文件；不要关闭系统安全保护。Source code ZIP/TAR 是源码，不是安装程序。
