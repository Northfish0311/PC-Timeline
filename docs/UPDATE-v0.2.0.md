# v0.2.0 页面与功能改进

- 重做概览、导航和页面间距，统一图标和状态提示。
- 时间轴增加关键词搜索、今天/最近 7 天/指定日期筛选和分页。
- 点击记录打开变化详情，展示版本、状态或磁盘容量的前后值。
- 增加真实采样的磁盘趋势和一周统计；点击某天进入相应时间轴。
- 增加检查间隔与磁盘事件阈值设置，保存后立即对后续检查生效。
- 自动刷新保留筛选条件、详情窗口、未保存的设置和阅读位置；未改变的列表不重复重建。
- 升级时保留旧历史，不编造旧记录没有保存的趋势、对比值。
- 不新增遥测、全盘扫描、自动删除或远程访问。

采样点上限为 1,440，事件上限为 2,000。日报仅导出当日已记录的变化数量和磁盘容量，不包含软件/设备名称或私人路径。

正式下载见 GitHub Releases 的 v0.2.0。普通用户只需选择安装版或便携版中的一个；Source code ZIP/TAR 是开发源码，不是安装程序。
