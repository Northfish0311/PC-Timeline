# 电脑时光机 v0.2.0 · 页面与功能升级

推荐下载 **PC-Timeline-Setup-0.2.0-x64.exe**，双击安装后打开桌面“电脑时光机”。不需要 Node.js、账号、管理员权限或命令窗口。

不想安装可下载 **PC-Timeline-Portable-0.2.0-x64.exe**。两种 EXE 只选一个即可，均适用于 Windows 10/11 x64。第一次启动便携版可能稍慢，因为需要临时解压运行环境。

## 本次改进

- 更紧凑的概览、统一图标、清晰的状态和采集失败提示。
- 时间轴支持关键词、类别、今天/最近 7 天/指定日期筛选及分页。
- 点击记录查看变化前后的状态、软件版本或磁盘容量。
- 磁盘趋势只使用真实采样点；每周统计可点击某天进入时间轴。
- 可设置检查间隔和磁盘变化阈值。
- 自动刷新保留筛选、阅读位置、详情窗口和未保存的设置。
- 升级自动保留旧记录，不补写旧版未保存的趋势或对比值。

验证：21 项自动化测试通过；四个页面在 1440、880、390 像素宽度完成截图和交互检查；打包版完成真实采集及设置保存/恢复测试。

## 更新和隐私

更新前退出旧软件，再运行新版安装程序。历史仍保存在当前用户的 `%APPDATA%\PC Timeline\data`，安装版和便携版共用这份历史。安装包不包含开发者的真实记录。

默认每分钟采集一次，最短 30 秒，最长 5 分钟。短暂插拔可能漏记。最多保留 2,000 条事件和 1,440 个磁盘采样点；不记录退出或关机期间的活动。磁盘差值尚不能定位到具体文件。

只在本机运行，不上传数据、不读取文件内容、不修改驱动、不自动删除文件。日报 PNG 不包含设备名称、软件名称或私人路径。

安装包未签名，Edge/SmartScreen 可能提示发布者未知。请只从本仓库下载并对照 **SHA256SUMS.txt** 核对，不要关闭系统安全保护。Source code ZIP/TAR 是开发源码，不是安装文件。
