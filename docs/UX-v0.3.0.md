# v0.3.0 交互与视觉改进

这轮重点是日常重复操作，而不是增加装饰。

## 已修正的交互

- 指定日期和“今天/最近 7 天”不再叠加冲突；切换时间范围会清掉指定日期。
- 阅读时间轴期间，新记录只显示更新提示。点击提示再载入，不直接插到正在读的位置前面。
- 切换页面保存各自的滚动位置，隐藏页面不反复重画；回到概览会重新检查图表尺寸。
- 详情可连续浏览上一条、下一条，支持方向键和 Escape 关闭。
- 设置显示未保存状态，提供撤销，保存按钮只在实际有更改时开放。
- 请求未结束时按钮保持锁定；保存或暂停后的旧请求结果不会覆盖新状态。
- 通知固定在页面角落，不再改变页面高度。连接失败保留旧数据并提供重连。
- 未开始记录的日期显示破折号，与已记录的零项变化区分。

## 视觉调整

统一主要字体层级，提高小字对比度，增大点击区域。保留简洁工具布局，分类采用克制的颜色，避免装饰遮挡数据。截图测试使用演示数据，不使用真实设备和软件名称。

正式下载见 GitHub Releases 的 v0.3.0。23 项自动化测试和浏览器交互回归已通过；截图覆盖 1440、880、390 像素宽度。慢请求、失败和迟到响应也进行了回归检查。
